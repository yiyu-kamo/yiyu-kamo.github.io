# あいの風とやま鉄道LED表示器シミュレーター
## したいこと
```
・富山駅高岡駅の切り替え
・実際の表示の反映と自由表示の切り替え
・自由表示の際にスクロールや行先表示などもすべて自由に設定できるように
```
## 実際にシミュレーターにする際の仕様
```
・接近表示は到着時刻1分前から表示するものとする
・列車案内は発車時刻30秒後に更新するものとする
・回送・当駅止めは到着10分後に回送発車とする
```

## LED表示器本体情報
```
・日本信号株式会社製D-3003Y-024-01
・東武日光線板倉東洋大前駅*1*2、伊勢崎線花崎駅*3に設置されている発車標と同じ製品であり、両駅ではフルカラー表示で使用されていることから、あいの風とやま鉄道で使用されている発車標もフルカラー表示は技術的には可能であると考えられる
・フォントはNEC FontAvenue:BMF ゴシック体*4
・縦24px、全角の場合横24px、半角の場合大抵12px（半角英字は12pxではない）（圧縮表示の場合は縦横は24pxまたは12pxではない
・標準色は橙であり、複数色を用いて重要度を分ける際は低いものから緑→橙→赤となる
・表示器に書かれている線番号のフォントはFrutigerLTPro-Roman
```

## 全体
```
・左から、（矢印） 種別 乗車位置 発車時刻 行先 （備考） （矢印）
・色は文字色の赤、橙、緑と、背景色の赤、橙、緑（背景色がある場合は文字色なし）
・乗車位置の色は基本橙、３番線だけ赤
・時刻の色は橙
・行先の色は基本緑、行先枠に入るが行先ではないもの（観光列車除く）は橙
・備考は基本橙、遅れは赤、接続案内は緑、停車駅案内は橙
・列車接近通過案内は赤（旧表示は橙）
・スクロールのみ表示が可能（高岡駅2行目のような感じ）
・スクロールで表示するお知らせが無いときはスクロールなしにすることが可能
・乗車位置は521系、413系のみ表示
・当駅止め、回送、通過、貨物、観光列車には種別、乗車位置、時刻を表示しない（団体も同じ可能性がある）
・遅れ表示は当駅始発以外は列車が到着していなくても表示し、当駅始発（当駅折返含む）は列車が到着してから表示する
・列車位置の矢印方向は、見ている側が進行方向を向いている場合は右で、進行方向と逆側を向いている場合は左
・スクロールの速度は60分の1秒（0.16666...秒）で1px
・列車の遅れが3分未満の場合と、回送、当駅止め、貨物、通過が遅延している場合は遅れとして表示されない
・列車接近案内は2026年7月10日8865D富山駅と2026年10月10日874D富山駅の場合列車が到着する約2分前から表示される
・列車通過案内は2026年7月10日貨物6080富山駅の場合列車が通過する約1分前から表示される
・列車接近通過案内が表示されたら1行スクロールはキャンセルされ、案内が終了しても続きは流れない
・列車接近通過案内は日本語4回点滅、英語2回点滅が基本となる（個体により点表示中に切り替わることがある）
・1つの行に何も表示されないことがある（富山駅の場合2行目にスクロールも列車も表示されない）
・列車位置表示がある際はスクロールは表示されない（富山駅）（高岡駅未確認）
```
### 日英切替
```
・列車種別、行先表示、乗車位置「３番線」は個体別に同時
・乗車位置、時刻は日英共に同じなため切り替えなし
・備考は列車ごとにズレあり
・備考スクロールは日英両方
・行スクロール、列車位置、備考の遅れは日本語のみ
・列車接近、列車通過は番線により違う
```
### 点滅切替表示間隔
```
・スクロール文字点滅は点1秒、滅1秒（背景色がある場合は文字だけ点滅）
・列車接近表示と列車通過表示は点から始まり、点1秒、滅0.5秒
・列車位置点滅は点から始まり、点1秒、滅1秒
```
### 「当駅止め」「回送」について
```
・「当駅止め」表示の列車が到着する時刻になった後、2026年9月23日543Mレの場合約28秒（停車から約8秒）で「回送」表示に変わるが、次の当駅止めも回送に変わることがある
・当駅止めでない営業列車が停車した際にも当駅止めが回送に変わることがある
・最初から回送として表示されていることがある
・2026年9月26日857Dレの場合、接近表示が消えた10～15秒後に「当駅止め」表示が「回送」表示に変わる
以上から、当駅止め→回送の切り替えについては不明点が多い
```
### 「貨物」「通過」について
```
・貨物列車が通過する際、「貨物」表示になる場合と「通過」表示になる場合の違いや切り替えについては不明点が多い
・2026年9月13日の場合富山駅1番線を17時55分、2026年10月3日の場合17時54分に一万三千尺物語が通過しており、その場合は「通過」と表示されていた
```
### 列車案内更新
```
・1行目に表示されている列車が発車する時刻になった後、2026年9月20日536M富山駅の場合約45秒（発車から約50秒）、2026年10月11日元ひだ13号回送富山駅の場合（富山到着18時54分）（回送発車放送（女）19時3分55秒）約1分（発車時刻を19時4分とする）（発車から約30秒後）、2026年10月11日537M高岡駅の場合約2分20秒（発車から約35秒）で列車案内が更新される
```

### 列車別備考案内
```
・泊駅で糸魚川方面行き列車と接続する列車は「泊駅で糸魚川方面行き列車に接続しております。」「This train connects to a train for Itoigawa at Tomari.」と表示される
・高岡駅を発車する列車で、富山駅で泊行き列車に接続する列車は「富山駅で泊行き列車に接続しております。」「This train connects to a train for Tomari at Toyama.」と表示される
・列車接続案内は、その列車の遅れが3分以上になると表示されなくなる
・列車接続案内は、実際に接続する列車でも接続案内が表示されない場合があり、駅ごとにも違いがある（553Mの場合、富山駅で接続案内があるが、高岡駅では接続案内がない）
```

### スクロール
```
・設定のミスなのか、通常スクロールが常時スクロールになっている不具合がある
・スクロールの間隔は20秒であり、スクロール→20秒間2行目列車表示→スクロール
・停車駅案内（ひだ号）が2行目スクロールになる不具合があり、これはひだ号が次発のときのみに発生する
```
### 日英切替
```
・列車が発車し今まで2行目に書かれていただった列車が1行目に移動した際、新しく1行目になった列車の「ワンマン」表示が日本語または英語表示固定になる不具合（同じ番線でも個体によって日英差あり）があり、列車が到着しても固定されたままであることがある
```

### 日英切替表示間隔
```
・列車種別、行先表示、乗車位置「３番線」は日7秒、英3秒
```
### 乗車位置
```
・３番線は、5&6番線の表示器に表示され、矢印は出されず、富山行きのみ
```
### 接近表示
```
・5&6番線の表示器では、３番線表示の列車の接近表示は表示されない
```
### 表示された列車の発着順
```
・5&6番線の表示器では、３番線表示が出ていて次発に通過がある場合、3番線の列車の発車より先に通過していくことがある（2026年10月11日8時16分AK22あいの風サイクルトレイン）
・一方の番線に列車が停車していても、次発の列車位置が表示される（2026年10月11日、先発は3番の535M、次発は4番に入る530M）
・「ワンマン」表示は先発のみ
・列車位置表示は次に到着する列車（先発次発関係なし）
・3番線に富山方面行きがいて、5番線に3番より先に発車する泊行きがいる時、5&6番線の表示器には先発に5番線の泊行き、次発に次の5&6番線の列車が表示され、5番線の泊行きが発車してその表示が消えた後に３番線表示が出る（2026年10月11日、5番線に437M、5番線次発439M、3番線543M）
```
### 列車出発後の更新時の表示違い
```
・列車発車後、「表示された列車の発着順」項に書いたような3番線の富山方面行きがいる場合、5&6番線の表示器は発車した列車の表示がなくなった後、1.3秒だけ5&6番線の新先発、新次発を表示し、その後3番線表示になる
```
### 列車位置表示
```
・備考がある場合、ワンマンやスクロールが終わった後に列車位置表示が行われる、ワンマン→Conductorless→富山駅で泊行き列車に接続しております。→This train connects to a train for Tomari at Toyama.→列車位置表示→ワンマンというようなループとなる
・スクロールで流す内容が無いときは、常に列車位置を表示し続ける
・スクロールで流す内容があるときは、スクロール→20秒間列車位置表示→スクロールのようなループかと予想する
```

### ディスプレイ表示器
```
・ディスプレイ表示器には3種類ある
  ・1:富山駅中央口外側＆高岡駅改札口に置いてある方面別のもの*1
  ・2:富山駅改札内＆のりかえ口＆待合室に置いてある全方面のもの*2
  ・3:富山駅＆高岡駅以外に置いてあるもの
  ・4:乗車位置変更があった際に置かれるもの*3
・発車する際、発車する列車の時刻が点滅する
・通常と違う番線から発車する場合、番線表示がオレンジ色になり、発車点滅と同じ間隔で点滅する
・発車点滅が開始すると接続案内が消える
・スクロール（備考表示、お知らせ、ご案内）の色は種類によって違う

・列車に遅れが生じた場合、時刻の下に遅れ約ｎ分と表示される
・お知らせ、ご案内のLED表示器との色の差が不明（橙だけで構成されているものの場合「【お知らせ】」などが橙、他が白という事例がある）
```
