# あいの風とやま鉄道LED表示器シミュレーター
## したいこと
```
・富山駅高岡駅の切り替え
・実際の表示の反映と自由表示の切り替え
・自由表示の際にスクロールや行先表示などもすべて自由に設定できるように
```
## 全体
```
・左から、（矢印） 種別 乗車位置 発車時刻 行先 （備考） （矢印）
・色は文字色の赤、橙、緑と、背景色の赤、橙、緑（背景色がある場合は文字色なし）
・スクロールのみ表示が可能（高岡駅2行目のような感じ）
・スクロールで表示するお知らせが無いときはスクロールなしにすることが可能
・乗車位置は521系、413系のみ表示
・当駅止め、回送、通過、貨物、観光列車には種別、乗車位置、時刻を表示しない（団体も同じ可能性がある）
・遅れ表示は当駅始発以外は列車が到着していなくても表示し、当駅始発（当駅折返含む）は列車が到着してから表示する
・列車位置の矢印方向は、見ている側が進行方向を向いている場合は右で、進行方向と逆側を向いている場合は左
・スクロールの速度は60分の1秒（0.16666...秒）で1px
・列車の遅れが3分未満の場合と、回送、当駅止め、貨物、通過が遅延している場合は遅れとして表示されない
・列車接近案内は2026年7月10日8865Dレの場合列車が到着する約2分前から表示される
・列車通過案内は2026年7月10日6080レの場合列車が通過する約1分前から表示される
・列車接近通過案内が表示されたら1行スクロールはキャンセルされ、案内が終了しても続きは流れない
・列車接近通過案内は日本語4回点滅、英語2回点滅が基本となる（個体により点表示中に切り替わることがある）
・1つの行に何も表示されないことがある（富山駅の場合2行目にスクロールも列車も表示されない）
```
### 日英切替
```
・列車種別、行先表示、乗車位置「３番線」は番線別に同時
・乗車位置、時刻は日英共に同じなため切り替えなし
・備考は列車ごとにズレあり
・備考スクロールは日英両方
・行スクロール、列車位置、備考の遅れは日本語のみ
・列車接近、列車通過は番線により違う
```
### 点滅切替表示間隔
```
・スクロール文字点滅は点1秒、滅1秒（背景色がある場合は文字だけ点滅）
・列車接近表示と列車通過表示は点から始まり、点1秒、滅0.5秒
・列車位置点滅は点から始まり、点1秒、滅1秒
```
### 「当駅止め」「回送」について
```
・「当駅止め」表示の列車が到着する時刻になった後、2026年9月23日543Mレの場合約28秒（停車から約8秒）で「回送」表示に変わるが、次の当駅止めも回送に変わることがある
・当駅止めでない営業列車が停車した際にも当駅止めが回送に変わることがある
・最初から回送として表示されていることがある
・2026年9月26日857Dレの場合、接近表示が消えた10～15秒後に「当駅止め」表示が「回送」表示に変わる
以上から、当駅止め→回送の切り替えについては不明点が多い
```
### 「貨物」「通過」について
```
・貨物列車が通過する際、「貨物」表示になる場合と「通過」表示になる場合の違いや切り替えについては不明点が多い
・2026年9月13日の場合富山駅1番線を17時55分、2026年10月3日の場合17時54分に一万三千尺物語が通過しており、その場合は「通過」と表示されていた
```
### 列車案内更新
```
・1行目に表示されている列車が発車する時刻になった後、2026年9月20日536Mレの場合約45秒（発車から約50秒）で列車案内が更新される
```
### 列車位置
```
・前々駅や前駅それぞれ発車時刻1分後になると前々駅～前駅間、前駅～当駅間のそれぞれの矢印が点滅する
・前々駅や前駅それぞれ到着時刻になると前々駅、前駅のそれぞれが点滅する
```
### 列車別備考案内
```
・泊駅で糸魚川方面行き列車と接続する列車は「泊駅で糸魚川方面行き列車に接続しております。」「This train connects to a train for Itoigawa at Tomari.」と表示される
・高岡駅を発車する列車で、富山駅で泊行き列車に接続する列車は日本語は「富山駅で泊方面行き列車に接続しております。」と表示されると思われるが、撮影できていない
・高岡駅を発車する列車で、富山駅で泊行き列車に接続する列車は英語は「This train connects to a train for Tomari at Toyama.」と表示される
・列車接続案内は、その列車の遅れが3分以上になると表示されなくなる
・富山駅を発車するあいの風ライナー金沢行きは、「停車駅は、小杉、高岡、石動、金沢です。」「This train stops at Kosugi,Takaoka,Isurugi,Kanazawa.」と表示される
・富山駅を発車するあいの風ライナー泊行きは、「停車駅は、滑川、魚津、黒部、入善、泊です。」「This train stops at Namerikawa, Uozu, Kurobe, Nyuzen, Tomari.」と表示される
・高岡駅を発車するあいの風ライナー金沢行きは、「停車駅は、石動、金沢です。」「This train stops at Isurugi,Kanazawa.」と表示されると思われるが、撮影できていない
・高岡駅を発車するあいの風ライナー泊行きは、「停車駅は、小杉、富山、滑川、魚津、黒部、入善、泊です。」「This train stops at Kosugi, Toyama, Namerikawa, Uozu, Kurobe, Nyuzen, Tomari.」と表示されると思われるが、撮影できていない
・特急ひだ号（速星停車）は、「停車駅は、速星、越中八尾、猪谷、飛騨古川、高山、下呂、美濃太田、岐阜、名古屋です。」「This train stops at Hayahoshi, Etchu-Yatsuo, Inotani, Hidafurukawa, Takayama, Gero, Mino-Ota, Gifu, Nagoya.」と表示される
・特急ひだ号（速星通過）は、「停車駅は、越中八尾、猪谷、飛騨古川、高山、下呂、美濃太田、岐阜、名古屋です。」「This train stops at Etchu-Yatsuo, Inotani, Hidafurukawa, Takayama, Gero, Mino-Ota, Gifu, Nagoya.」と表示される
・停車駅案内は一部の駅名には略字を使用し（例：「飛騨古川」の「騨」）、英語表示は駅名のマクロン記号は使用しない（例：「Etchu-Yatsuo」の「u」）
・2行目の列車の停車駅日スクロールが普通スクロールとして流れる不具合があり、これは1行目の列車では発生しない
・当駅止め、回送、通過、貨物は、「この列車は、ご乗車できません。」「This train is not in service.」と表示される
・団体にも何かしら表示されるそうだが、撮影できていない＊１
・観光列車は、「ご利用には事前のご予約が必要です。お乗り間違いにご注意ください。」「Reserved tickets are required.Please be careful not to board the wrong train.」と表示される
・最終列車は、「○○行き最終列車です。」「This is the last train for ○○.」と表示されるそうだが、撮影できていない
・2行目の列車の備考のスクロールが流れ切らなかった場合、そのスクロールの最初から改めて流す（日英別）
・列車接近通過案内が表示されたら備考スクロール（先発含む）はキャンセルされ、改めてキャンセル時の言語でスクロールが改めて開始される
・富山駅にある備考は高岡駅では2行目のスクロールに表示される（あいの風ライナー、停車駅など不明）
```

### 日英切替表示間隔
```
・備考の列車名は、日7秒、英3秒、停車駅日スクロール、停車駅英スクロール
・備考の列車名（ワンマン）は、日3.5秒、英3秒、ワンマン7秒、Conductorless3秒、停車駅日スクロール、停車駅英スクロール
・備考の接続案内（ワンマン）は、ワンマン7秒、Conductorless3秒、接続案内日スクロール、接続案内英スクロール
・備考の遅れ表示（ワンマン）は、ワンマン7秒、Conductorless3秒、遅れ表示7秒
・備考の全ての表示（スクロール以外）は、行スクロールが動いていても裏で継続して稼働している（ワンマン切り替えなども元のペースが裏で続いており、スクロールが終了しても切り替え間隔のまま続く）
```
### スクロール
```
・設定のミスなのか、通常スクロールが常時スクロールになっている不具合がある
・スクロールの間隔は20秒であり、スクロール→20秒間2行目列車表示→スクロール
・停車駅案内（ひだ号）が2行目スクロールになる不具合があり、これはひだ号が次発のときのみに発生する
```
### 日英切替
```
・列車が発車し今まで2行目に書かれていただった列車が1行目に移動した際、新しく1行目になった列車の「ワンマン」表示が日本語または英語表示固定になる不具合（同じ番線でも個体によって日英差あり）があり、列車が到着しても固定されたままであることがある
```
