# 発着番線等（2026年9月おわら風の盆時）
高山線列車のみ記載します（2026/9/1～3）
## 見方
### 発車
```
0000D 0000 八尾 ***
列番 時刻 行先 補
```
### 略称
```
・富山：富山
・八尾：越中八尾
・猪谷：猪谷
・名駅：名古屋
・ひだ：特急ひだ
・終着：終着駅到着時刻
・配布：整理券配布時刻
　・数字：整理券番号（実際は丸数字）
・集合：集合時間
```
### 止め
```
0000D 0000 猪谷 ***
列番 時刻 始発 補
```

富山駅　12:18発～20:50発の列車で「おわら風の盆」に行かれる方は、乗車整理券が必要です。　乗車整理券をお持ちでない方はご乗車いただけません。乗車整理券は概ね発車時刻の90分前に配布いたします。
