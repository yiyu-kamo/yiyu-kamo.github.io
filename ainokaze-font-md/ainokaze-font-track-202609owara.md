# 発着番線等（2026年9月おわら風の盆時）
高山線列車のみ記載します（2026/9/1～3）
## 見方
### 発車
```
000D 0000 富山 ***
列番 時刻 行先 補
```
### 略称
```
・ひだ：特急ひだ
・終着：終着駅到着時刻
・配布：整理券配布時刻
　・数字：整理券番号（実際は丸数字）
・集合：集合時間
```
### 止め
```
000D 0000 猪谷 ***
列番 時刻 始発 補
```
